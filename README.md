# Mini Test - Favian Hilmi Putradifa

Repository ini berisi penyelesaian untuk **Mini Test 1** (Small Program) dan **Mini Test 2** (Display the weather forecast for Jakarta for the next 5 days) menggunakan **PHP**.

---

## Instalasi & Konfigurasi

### 1. Clone Repository
```bash
git clone [https://github.com/FavianHilmi/Mini-Test---Stamps.git](https://github.com/FavianHilmi/Mini-Test---Stamps.git)
cd "Mini Test - Stamps"
```

### 2. Konfigurasi File .env (Khusus Task A.2)
Buat file bernama .env di root folder project, lalu isi dengan API Key dari OpenWeatherMap:
```bash
OPENWEATHER_API_KEY=api_key_here
```

## Cara Menjalankan Script
### Task 1 — Small Program
Script untuk menjalankan looping angka 100 hingga 1 dengan aturan FooBar, dan bilangan prima dilewati (tidak ditampilkan).
```bash
php smallProgram.php
```

### Task 2 — Display the weather forecast for Jakarta for the next 5 days
Script untuk mengambil ramalan cuaca Jakarta selama 5 hari ke depan dari OpenWeatherMap API dan menampilkan 1 nilai suhu per hari.
```bash
php weatherForecast.php
```
